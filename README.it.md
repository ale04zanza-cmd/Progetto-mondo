# Travel Explorer

Travel Explorer è un progetto front-end dedicato alla presentazione di destinazioni turistiche e capitali internazionali. L’applicazione combina un layout moderno, un storytelling visivo e componenti interattivi per offrire un’esperienza di navigazione immersiva e professionale.

## Obiettivo del progetto

Il progetto mira a creare una landing page di viaggio elegante e coinvolgente, pensata per far scoprire paesi, città e suggerimenti di viaggio in modo intuitivo. L’interfaccia è progettata per guidare l’utente in un percorso di esplorazione visiva, con un focus su usabilità, chiarezza e impatto estetico.

## Caratteristiche principali

- Hero section immersiva con call-to-action
- Navigazione principale con ricerca dinamica per destinazioni
- Sezione “Destinazioni” con card di paesi
- Sezione “Le capitali” con card delle città principali
- Carousel con controlli di navigazione manuali
- Toggle per il cambio tema chiaro/scuro
- Pagine dedicate a stati e capitali
- Sezione informativa con esperienze di viaggio e consigli stagionali
- Layout responsive per desktop e dispositivi mobili

## Stack tecnologica

- HTML5

- JavaScript vanilla

## Come eseguire il progetto

Poiché il sito è di tipo statico, non sono necessari framework né processi di build. È possibile aprire direttamente il file `index.html` nel browser oppure avviare un piccolo server locale:

```bash
python -m http.server 8000
```

Successivamente, aprire nel browser:

```text
http://localhost:8000
```
