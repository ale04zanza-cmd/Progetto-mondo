# Travel Explorer

Travel Explorer is a front-end project focused on presenting travel destinations and international capitals. The application combines a modern layout, visual storytelling, and interactive components to deliver an immersive and professional browsing experience.

## Project goal

The project aims to create an elegant and engaging travel landing page designed to help users discover countries, cities, and travel inspiration in an intuitive way. The interface is built to guide the user through a visual exploration journey, with a clear emphasis on usability, readability, and aesthetic impact.

## Key features

- Immersive hero section with call-to-action
- Main navigation with dynamic destination search
- “Destinations” section with country cards
- “Capitals” section with major city cards
- Carousel with manual navigation controls
- Light/dark mode toggle
- Dedicated pages for countries and capitals
- Informational section featuring travel experiences and seasonal recommendations
- Responsive layout for desktop and mobile devices

## Tech stack

- HTML5
- CSS3
- JavaScript vanilla
- Local graphic assets and images
- Static front-end architecture

## How to run the project

Since the website is static, no frameworks or build steps are required. You can open `index.html` directly in the browser or launch a simple local server:

```bash
python -m http.server 8000
```

Then open the following URL in the browser:

```text
http://localhost:8000
```
